# 银行个人信用风险评估模型

一个基于 Lending Club 公开数据集的端到端信用风险评分卡项目。本项目完整复刻了银行风控建模的核心流程，从数据清洗、探索性分析(EDA)、特征工程到模型构建与评估，最终输出可解释的业务策略。

## 项目目标

*   **核心任务**: 构建一个二分类模型，预测借款人是否会违约（Default）。
*   **业务价值**: 通过量化风险，为信贷审批、风险定价和额度管理提供数据驱动的决策支持。

## 数据概览

*   **数据源**: Lending Club Loan Data (2007-2015)
*   **样本量**: 经过严格的表现期筛选和数据清洗后，最终用于建模的样本为 **237,695** 条。
*   **标签定义**:
    *   **坏客户 (Bad, label=1)**: 贷款状态为 `Charged Off`, `Default` 或 `Late (31-120 days)`。
    *   **好客户 (Good, label=0)**: 贷款状态为 `Fully Paid`。
*   **坏客户占比**: **21.44%**

## 🛠️ 技术栈

*   **数据处理**: `pandas`, `numpy`
*   **可视化**: `matplotlib`, `seaborn`
*   **机器学习**: `scikit-learn` (逻辑回归), `lightgbm`
*   **开发环境**: Python 3.8+, Jupyter Notebook

## 项目流程

### 1. 数据清洗与预处理
*   **时间穿越防护**: 设定12个月的表现期，仅使用放款日至少在12个月前的样本，确保风险已充分暴露。
*   **信息泄露剔除**: 严格删除所有贷后产生的字段（如 `total_pymnt` 已还总额），避免模型作弊。
*   **缺失值与异常值处理**: 对高缺失率(>50%)特征直接删除；数值型特征用中位数填充，类别型用 "Missing" 填充；对 `annual_inc` (年收入) 进行 1%-99% 分位数截断(Winsorization)。

### 2. 探索性数据分析 (EDA)
*   **核心风险因子**: 发现 `int_rate` (利率) 和 `dti` (负债收入比) 与违约风险呈最强正相关。
*   **类别特征洞察**: `grade` (信用等级) 从A到G，违约率从 7.3% 单调递增至 47.0%，区分度极高。`term` (贷款期限) 为60个月的贷款违约率(34.9%)接近36个月(17.7%)的两倍。

### 3. 特征工程
*   **特征筛选**: 删除无信息量（如 `id`, `url`）和高基数（如 `emp_title`）特征。
*   **特征编码**: 对有序类别特征 `grade` 进行标签编码，对其他类别特征进行 One-Hot 编码。
*   **数据标准化**: 对逻辑回归模型输入的数值型特征进行 StandardScaler 标准化。

### 4. 模型构建与评估
对比了 **逻辑回归 (Logistic Regression)** 和 **LightGBM** 两种模型。

| 模型 | AUC | KS值 | 结论 |
| :--- | :--- | :--- | :--- |
| **逻辑回归** | **0.7018** | **0.2959** | **最终选用**，模型稳定且可解释性强 |
| LightGBM | 0.6979 | 0.2871 | 略逊一筹，可能因特征与目标间线性关系较强 |

> **模型表现**: KS值达到 **0.296**，表明模型具备良好的风险排序能力，符合金融风控模型的可用标准 (通常KS > 0.25即为可用)。

## 业务解读与策略建议

模型不仅是一个预测工具，更是业务决策的指南针。

1.  **准入策略**: 建议对 **DTI > 40%** 且 **信用等级为F/G** 的客户采取更严格的审批或直接拒绝。
2.  **定价策略**: `small_business` (小企业贷款) 的违约风险最高 (31.7%)，建议对此类用途的贷款进行风险定价上浮。
3.  **额度管理**: `revol_util` (信用额度使用率) 是重要风险信号，对使用率超过80%的客户应审慎授予高额度。
